# ISS-041: 3D is slow to open and rebuilds the whole building and street on every edit

- Severity: Medium
- Type: Improvement
- Status: In progress (2026-11-14, branch `ccr-e78bff39-u70ma7`): steps 1–2 fixed, needs retest; step 3 open; step 4 dropped (owner D4)
- Check ID: none
- Found: 2026-11-14, owner by hand (symptom) + Claude (code review), `main` at `06bf118`

## Start state
Studio, a branch with a drawn layout and the Neighborhood lane scene.

## Steps to reproduce
1. Switch Design → 3D → Design → 3D several times.
2. In a future split view: edit in 2D (move a chair) and watch the 3D update.

## Expected
Switching to 3D is instant and keeps the camera. One edit updates only what changed.

## Actual
- Owner (2026-11-14): live preview is hard because you must switch between 2D and 3D.
- From code: `StudioPage.vue` mounts the 3D view with `v-if="view === '3d'"` (line 249), so every switch creates the three.js viewer again and loses the camera. The 2D view already uses "mount once, then `v-show`".
- `building-viewer.ts` `setScene()` (line 106) clears and rebuilds the whole building on every layout change, and `placeSurroundings(layoutChanged || first)` (line 129) rebuilds the street too, because `layoutChanged` is true for every new layout object (`useLayoutDraft.change()` makes a new copy each edit).

Not measured: frame time and switch time. Use the existing benchmark (`designer/benchmark.ts`, `?bench=orbit`).

## Suspected cause
As above (code read; behaviour `unverified` in a browser).

## Fix direction
1. Keep the 3D view mounted after its first show (`v-show`), stop rendering while hidden. Selection is already shared (ISS-024).
2. Rebuild the surroundings only when the outline or the building bounds change, not on every new layout object.
3. Then rebuild per floor: compare each floor with the previous one and rebuild only changed floors.
4. Later (plan Phase 5): split view on wide screens with one shared viewer.
Measure with the benchmark before and after each step.

## How to verify the fix
Switching back to 3D shows the same camera at once (GIF). Moving one chair does not rebuild the street (benchmark or a dev counter). Benchmark numbers no worse than before.
