# ISS-022: Copy and paste (Ctrl/Cmd + C, V) do nothing

- Severity: Medium
- Type: Gap
- Status: Fixed, needs retest (branch `claude/bold-hypatia-sx8nkl`, second PR, 2026-11-13)
- Audit rows: CP1, KB1
- Found: 2026-11-13 (T91)

## Start state
Studio, select the Menu board.

## Steps
1. Press Ctrl+C, then Ctrl+V.
2. Press Ctrl+D.

## Expected (Figma)
Ctrl+C and Ctrl+V make a copy near the original (or in the view); Ctrl+D duplicates.

## Actual (Studio)
Ctrl+C and Ctrl+V do nothing: no new item in the Floors list. Ctrl+D works: the copy lands +75 cm in X, a second Ctrl+D is +75 cm again (X 1050, then 1125). Delete removes the selected piece without a confirm.

## Evidence
Test log T91 to T93.

## Suspected cause
`DesignShopEditor.vue` `onStudioKey` handles `d` (line about 989, `duplicateSelection`) and has no `c` or `v`.

## Fix direction
Ctrl/Cmd + C stores the selected piece ids in memory only (no clipboard, no secrets). Ctrl/Cmd + V pastes through the same path as `duplicateSelection`. Keep the rule that tables use "Duplicate look" (a copy of a table needs its own QR). Paste across floors only if the owner wants it.

## How to verify
Unit test for the paste offset; by hand: C then V makes a copy; tables follow the Duplicate look rule; undo removes it in one step.

## Open questions
- Should paste across floors be allowed?

## Work (branch `claude/bold-hypatia-sx8nkl`, 2026-11-13)
Ctrl/⌘+C copies the selected pieces and walls as they are (tables by id) into the layout editor, in memory only; Ctrl/⌘+V pastes 50 cm on (further each time), one undo step. One table alone asks which table (Duplicate look); tables in a set are not copied. Pasting on another floor shows a message until the owner decides. Unit and e2e.

## Owner answers built (branch `claude/bold-hypatia-sx8nkl`, second PR, 2026-11-13)
Owner left it to Claude: paste works on any floor. On the floor it came from: 50 cm on (further each paste); on another floor: in the same place (like Figma's paste into another frame). One table alone asks which table and lands on the floor shown. Unit tested.
