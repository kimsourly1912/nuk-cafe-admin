# ISS-001: Ctrl/Cmd+wheel zoom is far too fast

- Severity: High
- Type: Bug
- Status: Fixed, needs retest (branch `claude/bold-hypatia-sx8nkl`, 2026-11-13)
- Check ID: ZP4
- Test log: T01-T18 (zoom measurements)

## Start state
Studio floor plan open at any zoom, mouse over the canvas.

## Steps to reproduce
1. Hold Ctrl (Cmd on Mac) and turn the mouse wheel one notch over the canvas.
2. Repeat a few notches.

## Expected (Figma)
Smooth, small steps. Measured model: scale per event is about exp(0.005 x clamp(deltaY in px, -19, 19)), no easing. One mouse notch is about 10 % zoom. A large wheel delta is capped, so a fast spin never jumps.

## Actual (Studio)
Scale per event is e^(deltaY/100) (about 1.01^deltaY) with no cap and no easing. One notch (deltaY 100) multiplies the zoom by about 2.7, so the plan jumps several steps per notch. Reported by the owner as "very fast".

## Evidence
Numbers only so far, from JS-dispatched WheelEvents (direction and anchor are not reliable that way). A real wheel and trackpad pinch must be captured by the owner.

## Suspected cause
`app/features/branches/components/FloorPlanCanvas.vue`, `onWheel`: `zoomAround(point, 1.01 ** (event.deltaY * unit))`.

## Fix direction
Add a pure function in the floor-plan geometry module, for example `wheelZoomScale({ delta })`, returning `Math.exp(clamp(delta, -19, 19) * 0.005)`, and call it from `onWheel` (delta in pixels after the line/page `unit` conversion). Add unit tests: zero delta is 1, symmetric in sign, capped at both ends, a 100 px delta equals a 19 px delta. Record the change in a decision under D278.

## How to verify the fix
Unit tests pass. With a real mouse, one Ctrl+wheel notch changes the zoom by about 10 %, not 2.7x. Trackpad pinch stays smooth. Capture a GIF of both apps for one notch and for ten notches.

## Open questions
Trackpad pinch (ctrlKey wheel events with small deltas) needs a real-device check after the fix.

## Work (branch `claude/bold-hypatia-sx8nkl`, 2026-11-13)
`wheelZoomFactor` in `designer/camera.ts`: exp(0.005 × delta capped at ±19 px), unit tested. Real wheel and pinch still to check by hand.
