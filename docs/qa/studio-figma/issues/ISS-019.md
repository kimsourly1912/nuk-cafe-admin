# ISS-019: Edit points: right angles kept by default; Figma moves points freely

- Severity: Medium
- Type: Gap
- Status: Open (owner decided: follow Figma; details to collect, see below)
- Audit rows: DR5
- Found: 2026-11-13 (owner by hand, T65)

## Start state
Studio, Edit points tool (`P`) on a floor outline.

## Steps
1. Press `P`. Drag a corner; then drag with Alt; then drag a side.
2. Double-click a side; click a round handle on a side; click a corner and press Delete.
3. Press Enter, then repeat and press Esc.

## Expected (Figma vector edit, general knowledge)
- A dragged point moves freely; Shift limits the move to a straight line or 45 degrees.
- Double-click a segment adds a point. Delete removes the selected point. Enter or Esc leaves the mode.
- Changes are one undo step.

## Actual (Studio)
Owner: not like Figma. From the code and the on-screen help:
- A dragged corner keeps right angles unless Alt is held (the help panel says so). This is the opposite default.
- Arrow keys move the corner 5 cm, 25 cm with Shift (matches Figma's small and big nudge).
- A single click on an edge opens wall, railing, open, door or window choices: Studio-only, fine.

## Evidence
Test log T65; help panel screenshot (edit points).

## Suspected cause
`FloorPlanCanvas.vue` line 783: `liveShape.value = moveCorner({...}, gesture.index, to, !event.altKey)`; the last argument is "keep right angles". Arrow keys at about line 1004 use the same default.

## Fix direction
Free move by default; Shift constrains (same rule as ISS-013/018). Right angles can stay as an optional behavior on a key or snap, if the owner wants it for walls. Add unit tests for `moveCorner`.

## How to verify
By hand: corner moves freely; Shift constrains; double-click adds, Delete removes; Esc leaves; one undo step each.

## Open questions
- What exactly did not feel like Figma (default angle, selecting several points, Esc/Enter result)? Ask the owner.

## Verified by Claude (2026-11-13, click tests)
- Studio Edit points: clicking the round handle on a side adds a corner and selects it (T69). Pressing Delete with that corner selected removes it and the side goes back to its old length (575 cm) (T69).
- A double-click on a side selected the edge (Back edge 1, 575 cm) but no corner was added at that point (T70, recheck; the help panel says a double-click adds one).
- Enter leaves Edit points and returns to Select (T71).
- Corner drag with Shift or Alt cannot be tested with my tool (no held keys while dragging).

## Owner confirmation (2026-11-13, T70, T73)
Owner checked by hand: the double-click on a side that should add a corner and the Alt/Shift corner drag do not work like Figma. Treat double-click add as a bug: the help panel promises it, but only the edge is selected (T70).
