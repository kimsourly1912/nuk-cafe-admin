# ISS-021: Layers list (Floors panel): no range select, no canvas hover, no hide or lock

- Severity: Low
- Type: Gap
- Status: Open (needs owner decision on scope)
- Audit rows: LY2, LY3, LY4
- Found: 2026-11-13 (T86 to T90)

## Start state
Studio, Ground floor, left panel Floors list.

## Steps
1. Click the Coffee station row, then Shift + click the "u" row.
2. Hover a row.
3. Double-click a row; look for hide and lock icons on hover.

## Expected (Figma, verified for hover and icons on 2026-11-13)
- Shift + click selects a range; Ctrl/Cmd + click toggles.
- Hovering a row outlines the object on the canvas.
- Eye and lock icons appear on hover; double-click renames in the row.

## Actual (Studio)
- Click selects the piece and Shift + click selects only the second row (no range).
- Hover highlights the row only (checked with the Dog row; recheck with a row visible on the plan).
- No hide or lock icons. Double-click selects the piece; rename is in the inspector Name field.
- Search icon opens a filter box for floors and pieces: matches the idea of Figma's layer search.

## Evidence
Test log T86 to T90.

## Suspected cause
Not read yet (Floors list in `DesignShopEditor.vue`).

## Fix direction
Owner decision first: Studio is a floor-plan list, not a layer tree. Cheap wins: range and toggle select, hover outline on the canvas. Hide and lock need a data model change (stored per piece), so write an ADR only if the owner wants them.

## How to verify
By hand: Shift and Ctrl/Cmd click in the list; hover outline; icons only if built.

## Open questions
- Does the owner want hide and lock for pieces?
