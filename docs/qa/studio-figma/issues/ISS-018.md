# ISS-018: Wall tool: straight-only by default; Figma lines are free with Shift for 45 degrees

- Severity: Medium
- Type: Gap
- Status: Open (owner decided: follow Figma; details to collect, see below)
- Audit rows: DR3, DR4
- Found: 2026-11-13 (owner by hand, T64)

## Start state
Studio, Draw wall tool (`W`).

## Steps
1. Press `W`. Click a start point.
2. Move the mouse in a rough diagonal. Look at the preview and the length label.
3. Hold Shift while moving; then hold Alt.
4. Click the end point; keep clicking to chain; click the first point again; try Escape, Enter, double-click.

## Expected (Figma Pen/Line, general knowledge)
- The segment follows the mouse freely, at any angle.
- Shift locks the angle to 45 degree steps. The key is read live, also when pressed without moving the mouse.
- Clicking the first point closes the shape. Enter or Esc finishes. Delete removes a selected point.

## Actual (Studio)
Owner: not like Figma. From the code:
- Every wall point is forced to run straight across or down from the previous point. Alt makes it free. This is the opposite of Figma.
- Shift is not used for angle lock in the wall tool.
- The same point twice (or a double-click) ends the chain; Escape did not leave the tool on the first press in T62.
- No close-the-loop behavior for walls (closing exists only for the floor outline drawing).

## Evidence
Test log T61, T62, T64.

## Suspected cause
`FloorPlanCanvas.vue` `drawPoint()` (about line 444): `if (!from || free) return point` otherwise `Math.abs(point.x - from.x) >= Math.abs(point.y - from.y) ? { x: point.x, y: from.y } : { x: from.x, y: point.y }`. `free` is `event.altKey` in pointer move (about line 663) and in `tap()` (about line 876). `tap()` for mode `wall` chains `wallStart`.

## Fix direction
Same rule as ISS-013: free by default, Shift snaps to 45 degrees (a pure function `constrainAngle` with unit tests), keys read live from `keydown`/`keyup`. Keep grid snap with Ctrl/Cmd for fine steps. Decide wall-chain finish keys (Esc, Enter, double-click) and a close-loop click on the first point.

## How to verify
Unit tests for the angle function. By hand: free diagonal by default, Shift gives 0/45/90, preview and result agree, Esc finishes and leaves the tool.

## Open questions
- Owner said "not like Figma" without detail: ask the owner what exactly felt wrong (angle, finishing, undo?).
- Walls in a shop are mostly straight. Keep Shift as the straight lock and free by default, as in ISS-013?

## Verified by Claude (2026-11-13, click tests with modifier keys)
- Figma Pen, start then a second click 50 px right and 40 px down: free path 13.5 x 10.5 (T66). Same clicks with Shift: 12 x 12, so Shift snaps to 45 degrees (T67).
- Studio Draw wall, clicks on a diagonal (T68): no key gave a horizontal wall (forced straight); Shift gave a vertical wall (Shift has no effect, still forced straight); Alt gave a free diagonal wall.
- So the Figma side of "free by default, Shift = 45 degrees" is now verified. Closing a path by clicking the first point is not verified in Figma yet.
