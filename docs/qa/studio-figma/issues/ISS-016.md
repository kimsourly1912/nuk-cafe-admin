# ISS-016: Shape tool: a single click creates nothing (Figma makes a default-size shape)

- Severity: Low
- Type: Improvement
- Status: Fixed, needs retest (branch `claude/bold-hypatia-sx8nkl`, fifth PR (small items), 2026-11-13)
- Audit rows: DR1, DR3, TL4
- Found: 2026-11-13

## Start state
Studio, Ground floor, Select tool, nothing selected.

## Steps
1. Press `S` (Shape tool). Top bar shows "Shape · Ground floor | Rectangle | Circle | Cancel | Done".
2. Single-click on an empty spot of the plan.
3. Compare: Figma, press `R`, single-click on the canvas.

## Expected (Figma)
A single click with the rectangle tool makes a default 100 x 100 shape at the click point, selected, tool returns to Move.

## Actual (Studio)
Nothing is created. The tool stays in Shape and only the hint is shown ("Drag to draw a block ..."). A drag from (700,400) to (790,440) works: it makes a 225 x 100 cm "Block", selects it and returns to Select (this part matches Figma).

## Evidence
- Figma: click made Rectangle 100 x 100; drag shows a size label "18 x 11" while drawing.
- Studio: block drag result, no result after click (see Test log T58-T60).

## Suspected cause
`FloorPlanCanvas.vue` `onPointerUp` (~line 853): `if (finished.type === 'room' && room) { if (props.mode === 'shape') emit('block', room.bounds) ... }`. `room` is only built from a moved drag, so a click without movement emits nothing. There is no click-only branch for the shape/room tool.

## Fix direction
In the `room` gesture, when the pointer did not move and mode is `shape`, emit `block` with a default rectangle centered on the click (suggest 100 x 100 cm, snapped like other pieces; circle tool the same with a round block). Keep drag behavior as is. Add a unit test for click-only and a test that drag still works.

## How to verify
Press S, click once: a 100 x 100 cm block appears selected, tool back to Select. Press S then O, click: a round block. Drag still makes the dragged size.

## Open questions
- Is a default size wanted, or should Studio keep drag-only because the hint already teaches it? (Low priority.)

## Other drawing notes (not issues)
- Draw wall (`W`): click start, click end gives a live length label, walls continue from the last end. This matches Figma's pen/line chain idea. After one `Escape` the Draw wall bar was still shown; `P` then `Escape` returned to Select. Recheck whether the first Esc should end the chain and leave the tool (see Test log T62).

With Shape, a click (under the drag slop) makes a 100 x 100 cm shape centred on the point, selected, like Figma's rectangle. A drag still draws its own size. Room keeps drag-only: a click there adds nothing (a 1 m room has no use). e2e: `shop-designer.test.ts` (Shape click).
