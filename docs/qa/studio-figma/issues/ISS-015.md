# ISS-015: Shift and Alt do nothing while resizing, and Shift does not snap rotation

- Severity: Medium
- Type: Gap
- Status: Open
- Check ID: TR3, TR5
- Test log: T54, T55

## Start state
Studio 2D, a non-round piece (for resize) or any table (for rotate) selected.

## Steps to reproduce
1. Hold Shift and drag a corner handle.
2. Hold Alt and drag a corner handle.
3. Hold Shift and drag the rotate handle.

## Expected (Figma)
Shift while resizing keeps the ratio. Alt resizes from the center. A size label shows while resizing. Shift while rotating snaps to 15 degree steps (after ISS-013). (From the Audit's general-knowledge expectation; the Figma side was only confirmed for the free resize and the size label, T46.)

## Actual (Studio)
Owner by hand: resize and rotate with Shift do not work at all. In the code the resize gesture ignores Shift and Alt completely, and Shift on rotate does the opposite of Figma (it frees the angle). There is also no keyboard help for them.

## Suspected cause
`FloorPlanCanvas.vue`, pointer move, `gesture.type === 'resize'` (about lines 708-712): it only passes `corner`, `delta`, `round`, `min` and `max` to `resizeFromCorner`. It reads no `shiftKey` or `altKey`. Rotate is at about line 703. Corner handles are also hidden when the frame is smaller than 56 px on screen (`handleCorners`, about line 420), so a small piece cannot be resized by handle at low zoom.

## Fix direction
Add two options to `resizeFromCorner` (in the geometry module): `keepRatio` (Shift) and `fromCenter` (Alt), covered by unit tests with the existing min and max limits. Pass them from the key state on every pointer move so the user can press the key mid-drag. Show the size while resizing. Rotate: see ISS-013. List the keys in `STUDIO_DRAG_KEYS`.

## How to verify the fix
Unit tests for both options. By hand: Shift + corner drag keeps the ratio; Alt + corner drag grows around the center; both together keep the ratio around the center; the size shows while dragging.
