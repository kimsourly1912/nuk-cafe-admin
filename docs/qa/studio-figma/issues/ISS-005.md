# ISS-005: Zoom limits differ from Figma

- Severity: Low
- Type: Gap
- Status: Fixed, needs retest (branch `claude/bold-hypatia-sx8nkl`, fifth PR (small items), 2026-11-13)

## Steps to reproduce
Zoom all the way out and all the way in, in both apps. Read the percent.

## Expected (Figma)
About 2 % to 25,600 %. This is from memory and is not verified in this test.

## Actual (Studio)
Measured 2026-11-13 on staging, window 2560 x 917 (test T24): Ctrl+minus stops at 14%, Ctrl+plus stops at 564%; more presses change nothing. The percent limits move with the window size, because the code limits the view width (`MIN_VIEW_CM` 200, `MAX_VIEW_CM` 8000), not the percent. Constants `MIN_ZOOM` 0.05 and `MAX_ZOOM` 8 (5 % to 800 %) are never reached here. Figma side not run.

## Suspected cause
Constants in `FloorPlanCanvas.vue`.

## Fix direction
First verify Figma's limits. A floor plan may not need 25,600 %; the owner decides whether to widen the range.

## How to verify the fix
Zoom to the limits and read the label.

## Update (2026-11-13, with ISS-028)
The camera change for ISS-028 made the limits fixed percentages: 10 % to 800 % on every window size (`ZOOM_LIMITS` in `designer/camera.ts`). Retest the label at both ends. Whether to widen the range toward Figma's stays an owner decision.

## Work (branch `claude/bold-hypatia-sx8nkl`, fifth PR (small items), 2026-11-13)
Zoom now goes from 2 % to 25,600 % on every window size (`ZOOM_LIMITS` 0.02 to 256 px/cm; Fit and zoom stop there, not at a view width). The range is what Figma users report; Figma's documentation does not state it. The 1 m grid lines fade far out like the 10 cm ones (`majorGridOpacity`). Unit: `designer-camera`; e2e: zoom menu steps.
