# ISS-024: Selection is lost when going from 3D back to 2D

- Severity: Low
- Type: Improvement
- Status: Not reproduced, needs retest with exact steps (branch `claude/bold-hypatia-sx8nkl`, 2026-11-13)
- Audit rows: ST1
- Found: 2026-11-13 (T95, owner answer T102)

## Start state
Studio, 2D, the Round block selected.

## Steps
1. Switch to 3D with the 2D/3D buttons.
2. Switch back to 2D.

## Expected
The same piece stays selected and the view stays the same (owner: yes, wanted).

## Actual (Studio)
3D shows the piece with an "Edit in 2D" button. After going back to 2D the selection is cleared and the floor properties show.

## Evidence
Test log T95, T102.

## Suspected cause
Not read yet (2D/3D switch in `DesignShopEditor.vue`; the URL gets `?view=3d`).

## Fix direction
Keep the selection id in the editor state across the view switch, drop it only if the piece no longer exists. Zoom and pan should return to what they were.

## How to verify
Select a piece, 3D, 2D: still selected; same zoom and position.
