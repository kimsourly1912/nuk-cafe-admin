# ISS-014: Alt + drag copy works but does not feel like Figma

- Severity: Medium
- Type: Improvement
- Status: Open (owner described the symptom 2026-11-13)
- Check ID: TR6
- Test log: T52, T53

## Start state
Studio 2D, clean page, a piece or table on the plan.

## Steps to reproduce
1. Hold Alt, press on a piece and drag it.
2. Release.

## Expected (Figma)
From general knowledge, not re-verified in this test: with Alt held when the drag starts, the original stays in place and a copy follows the pointer right away, with a copy cursor. Pressing Alt in the middle of a drag turns the move into a copy (the original returns to its start); releasing Alt turns it back into a move. The result is decided by the Alt state on release and shown live all the time. One undo removes the copy.

## Actual (Studio)
Owner by hand: Alt + drag does make a copy, but it is not smooth like Figma. The owner wants the same flow and behavior as Figma. My tool cannot send Alt during a drag, so the feel was not reproduced here; the causes below come from the code.

## Suspected cause (from the code, not confirmed)
- `FloorPlanCanvas.vue` about line 841: the copy is decided at pointer up, from `event.altKey` at that moment, not when the drag starts. Pressing or releasing Alt during the drag changes the result.
- During the drag the original moves with the pointer (no ghost left behind), so nothing shows that a copy will be made.
- A table cannot be copied (each has its own QR code). A table's Alt + drag asks which table the copy is (`DesignShopEditor.vue` about line 962), which may feel like a failure.
- On Windows, Alt alone can focus the browser menu bar and take the keyboard from the page.

## Fix direction
Match Figma's flow. While a piece is dragged: if Alt is held (at press or at any moment during the drag), keep the original drawn at its start position and draw the moving preview as the copy; when Alt is released, the original follows the pointer again. Track Alt with key events as well as pointer events, so it toggles even when the pointer is still. Show a copy cursor while Alt is held. Keep the rule that a table's copy asks which table it is, at release. Add tests: pointer down, move, Alt down, move, release emits copy at the drop point; Alt up before release emits move.

## How to verify the fix
Alt + drag a piece: the original stays, the copy lands where released, one undo removes the copy. Alt + drag a table: the user is asked which table it is, and cancelling leaves the plan unchanged.
