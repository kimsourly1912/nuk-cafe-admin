# ISS-032: The yellow ring is far from the element on hover and select

- Severity: Medium
- Type: Bug
- Status: Open
- Audit rows: SE (selection frame), IN (handles)
- Found: 2026-11-13 (owner, with screenshot)

## Steps
1. Hover a piece (for example the "Block"). Then click it.
2. Look at the distance between the yellow frame and the piece.

## Expected (Figma)
The selection frame sits exactly on the edge of the element. The handles are small squares on the corners of that frame.

## Actual (Studio)
The frame is about 10 to 15 px away from the piece on every side, so it looks like it floats around the element.

## Evidence
`evidence/ISS-032/studio-ring-far-from-block-owner.png`.

## Suspected cause (read from code)
`FloorPlanCanvas.vue` (~line 1900+): the handles use `handleCorners(table.extent.width + 12, table.extent.depth + 12)`, so the frame is 12 cm bigger than the piece, and the same padding idea is used for other pieces (`selectionFrames`, line 339). The padding is in plan cm, so on screen it changes with zoom instead of staying a constant pixel gap (or zero).

## Fix direction
Draw the frame on the real bounds of the piece (padding 0), stroke 1 px with `vector-effect="non-scaling-stroke"`, handles as fixed-size squares in screen pixels (use `perPixel`). Do the same for the hover outline. Check tables, furniture, shapes and multi-selection.

## How to verify
Hover and select at 50%, 100% and 400%: the frame touches the piece edge at every zoom. Rotated pieces too.
