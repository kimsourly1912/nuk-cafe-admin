# ISS-003: Zoom menu has no typed percent field

- Severity: Medium
- Type: Gap
- Status: Fixed, needs retest (branch `claude/bold-hypatia-sx8nkl`, 2026-11-13)
- Check ID: ZP (zoom menu)

## Steps to reproduce
1. Open the zoom percent menu in the Figma toolbar. Open the zoom menu in Studio.

## Expected (Figma)
The menu has an input where you type an exact percent, plus zoom in, zoom out, fit, 50 %, 100 %, 200 %.

## Actual (Studio)
The menu has preset items only. No typed percent.

## Evidence
| File | Shows |
|---|---|
| evidence/ISS-003/ (to add) | Both menus open, side by side |

## Suspected cause
Menu items are built in `StudioToolbar.vue` (around line 39) and `DesignShopEditor.vue` (around lines 1031 and 1098). `FloorPlanCanvas` already exposes `zoomTo(percent)`.

## Fix direction
Add a numeric input at the top of the menu that calls `zoomTo`, clamped to the allowed range. Use Nuxt UI components and follow the forms reference. Reject non-numbers and keep the previous value.

## How to verify the fix
Type 150, press Enter: the canvas is at 150 % and the label shows 150 %. Type 99999: clamps to the maximum. Type letters: ignored.

## Work (branch `claude/bold-hypatia-sx8nkl`, 2026-11-13)
A field at the top of the zoom menu: Enter zooms to the typed percent (clamped to 10–800 %) and closes the menu; not a number keeps the zoom. `parseZoomPercent` unit tested; e2e types 150, 99999 and letters.
