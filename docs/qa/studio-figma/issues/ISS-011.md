# ISS-011: Shift + drag on a piece deselects it instead of moving it in a straight line

- Severity: Medium
- Type: Bug
- Status: Open
- Check ID: TR1
- Test log: T40, T43

## Start state
Studio 2D, Ground floor, clean page, a table (P02) on the plan.

## Steps to reproduce
1. Select table P02 (or leave it unselected).
2. Hold Shift, press on P02 and drag it.

## Expected (Figma)
Shift + drag moves the object and locks it to a straight horizontal or vertical line. Shift + click without moving toggles the object in or out of the selection. Not re-verified in this test; from general knowledge of Figma.

## Actual (Studio)
Owner tested by hand: the piece is deselected as soon as the press happens and does not drag. My tool's Shift + drag moved both X and Y (no lock, T40), which fits the same cause. The shortcut list in the app and the code comment both promise "Shift: Drag: straight across or down", so the feature exists but cannot be reached this way.

## Suspected cause
`app/features/branches/components/FloorPlanCanvas.vue`, pointer-down handler (about lines 610-614): `if (pickable && event.shiftKey && event.pointerType !== 'touch') { emit('toggle', { kind, id }); return }`. The toggle runs on press and returns before any drag gesture starts. The axis lock code (about lines 723 and 767) only runs on pointer move, so it works only if Shift is pressed after the drag has already started.

## Fix direction
On press with Shift over a piece, do not toggle yet. Start the normal drag gesture and remember that a toggle is pending. On release: if the pointer did not move, toggle the selection then (like Figma); if it moved, drag the piece (or the selected group, if it is part of it) with the axis lock, and do not toggle. Decide with the owner what Shift + drag on an unselected piece does (Figma adds it and moves it). Keep touch behavior unchanged. Add tests: press, move, release with Shift moves on one axis only; press and release without a move toggles.

## How to verify the fix
By hand: Shift + drag a selected table moves it straight across or down and keeps it selected. Shift + click without moving still adds or removes it. Shift + drag also works on a group and on a wall.
