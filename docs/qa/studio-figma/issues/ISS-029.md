# ISS-029: No live size label while drawing or resizing

- Severity: Medium
- Type: Gap
- Status: Open (owner: Figma has it, Studio does not)
- Audit rows: DR2, TR3
- Found: 2026-11-13 (owner by hand, T117, T118)

## Steps
1. Studio: press S (or R) and drag a shape; also drag a resize handle of a piece.
2. Figma: press R and drag; also drag a resize handle.

## Expected (Figma, verified)
A small label "width x height" follows the shape while drawing and resizing.

## Actual (Studio)
No label while drawing a Shape or Room. No size label while resizing (also in ISS-015). Wall drawing does show a live length label (T61), so the pattern exists.

## Suspected cause
Studio draws the preview from `roomPreview` and the resize gesture in `FloorPlanCanvas.vue` but only the wall tool renders a length label. Not read in detail.

## Fix direction
Reuse the wall's length label component for the room, shape and resize previews: show width x depth in cm next to the pointer. Update live with the preview (see ISS-017 for live keys). Add the same label for rotate (angle) as a follow-up, like Figma.

## How to verify
By hand: drag a shape, room and resize handle: the label shows and matches the inspector after release.
