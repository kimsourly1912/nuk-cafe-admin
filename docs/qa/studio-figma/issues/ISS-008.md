# ISS-008: Right-click menu is much smaller than Figma's and has no Copy, Paste or Bring to front

- Severity: Low
- Type: Gap
- Status: Needs owner decision
- Check ID: SE7, KB1, KB2
- Test log: T37, T38

## Steps to reproduce
1. Right-click an unselected object (Studio: table P02; Figma: Rectangle 1).

## Expected (Figma)
Right-click selects the object under the pointer, then opens a menu. The menu has Copy, Paste here, Paste to replace, Copy/Paste as, Move to page, Bring to front (]), Send to back ([), Group selection, Flatten, Create component, Show/Hide, Lock/Unlock, Flip horizontal and vertical, and more.

## Actual (Studio)
Right-click selects the table (matches Figma) and opens a menu with: Rotate 90° (R), Duplicate look (Ctrl D), Edit table, View QR, Zoom to selection (Shift 2), Remove from map (Del). No Copy, Paste, order or Lock/Hide. "Duplicate look" is intentional: a table cannot be copied because each table has its own QR code (a toast says so, `DesignShopEditor.vue` line 571), so Duplicate look places another table with the same look.

## Suspected cause
Menu items are defined in `DesignShopEditor.vue` (the items near `Zoom to 100%`). The set is intentionally Studio-specific.

## Fix direction
Owner decision. A floor plan has no layers to group or flatten, so most of Figma's menu is Not needed. Candidates to consider: Copy and Paste (check KB1 first: do Ctrl+C and Ctrl+V work?), Lock/Unlock and Hide (check LY4). Copy and Paste of a table would need the same rule as Duplicate look (a new table must be chosen).

## How to verify the fix
After the owner picks items: each item in the menu works from the menu and from its shortcut, for one item and for a multi-selection.
