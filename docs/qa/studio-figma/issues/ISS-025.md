# ISS-025: No command search (Ctrl+/) and no shortcut list in Studio

- Severity: Low
- Type: Gap
- Status: Open (owner confirmed 2026-11-13: follow Figma)
- Audit rows: TL6, KB4
- Found: 2026-11-13 (T106 to T109)

## Steps
1. Studio: click the plan, press Ctrl+/ then Shift+/ (the ? key).
2. Figma: press Ctrl+/; open the Help button at the bottom right.

## Expected (Figma, verified 2026-11-13)
Ctrl+/ opens a search box with recent actions and suggestions. The Help menu lists "Keyboard shortcuts" (Ctrl+Shift+?).

## Actual (Studio)
Ctrl+/ does nothing. Shift+/ shows nothing. No shortcut list was found by key (a menu button may exist: not found yet).

## Suspected cause
`STUDIO_SHORTCUTS` exists in `studio.ts` (used for menus and tooltips) but no panel shows it as a list and no command search is wired. Not read in detail.

## Fix direction
Cheapest useful step: a "Keyboard shortcuts" panel built from `STUDIO_SHORTCUTS` (one source, no duplicate list), opened by `?` and from a menu. Command search only if the owner wants it (more code, lower value for a floor editor).

## How to verify
By hand: `?` opens the list; every key in the list works.

## Open questions
- Does the owner want a command search at all?
