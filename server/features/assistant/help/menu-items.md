# Menu items

**Menu → Menu items** lists everything customers can order. Switch between the grid and list view with the buttons in the toolbar. Filter by **Category**, search by name, and use the tabs **All**, **Draft**, **Published**, **Archived**.

A new item is created as a **Draft**: customers don't see it until you publish it.

## Create a menu item

1. Press **New menu item** (or **N**).
2. **Image** (optional): upload a JPEG, PNG or WebP photo, at most 5 MB.
3. **Name** and **Category** (required). The category must be one without subcategories: choose the subcategory, not its main category.
4. **Description** (optional).
5. **Options and prices**: see below. Without option sets the item has one version: enter its **Price**.
6. **Add-ons** (optional): **Add add-on group** to offer extras from the Add-ons library.
7. **Availability** (optional): choose rules to limit when it's sold. None means whenever the branch is open. Its category's rules apply too.
8. Press **Create**. It's saved as a draft.
9. To put it on the menu, open the item's **⋮** menu in the list and choose **Publish**.

On a phone the editor shows one section at a time (Details, Prices, Add-ons, Availability) with Save at the bottom.

## Options and prices (versions)

- **Add option set** adds a set from the Options library, like Size or Temperature. An item can have up to 2.
- Each combination of values is a **version**, for example "Hot / Small", "Iced / Large". The grid shows one row per version with a switch (**Sell …**) and a price.
- Switch off the versions you don't sell. A version that's on needs a price.
- Removing an option set rebuilds the grid; check the prices again.

## Add-ons on an item

- **Add add-on group** picks a group from the Add-ons library. Up to 10 groups; use the arrows to order them.
- By default the group's rules (At least / At most) and prices come from the library. Turn on **Own rules for this item** to set different rules for this item only.
- Change an add-on's price here to charge a different price on this item only.

## Publish, unpublish, archive, restore

From the item's **⋮** menu in the list:

- **Publish**: puts a draft on the customer menu. It needs at least one version switched on with a price.
- **Unpublish**: takes it off the menu and back to draft.
- **Archive**: hides it and makes it read-only. Past orders keep it. Several at once: **Select**, tick the items, **Archive selected**.
- **Restore** (on an archived item): back to draft, editable again.

To mark something out of stock for today, don't unpublish it: staff use **Sold out** in the counter app.

## Edit a menu item

Click the item's name (or **⋮ → Edit**), change it, then **Save**. Changes to a published item show on the customer menu at once.

## Common problems

- **"Switch on and price at least one version before publishing."**: open the item, switch on a version in Options and prices and give it a price, save, then publish.
- **"That category has sub-categories; put the item in one of them."**: choose one of its subcategories as the category.
- **"Choose an active option set / add-on group / category"**: something the item uses was archived. Remove it from the item or restore it in its library.
- **"This menu item is archived. Restore it from the list to edit it."**: archived items are read-only; **Restore** first.
- **An option set can't be added**: the item already has 2, or the set is archived.
- **The item doesn't show on the customer menu**: see "When does a customer see an item?" in the menu overview.
