# Add-ons

**Menu → Add-ons** is the library of **add-on groups**: extras customers can add to an item, like "Milk" (Oat milk, Soy milk) or "Syrups" (Vanilla, Caramel), each with a default price. Each card shows **Required** or **Optional**, the rule, the add-ons with prices and how many menu items use it. Tabs **All**, **Active**, **Archived**; search by group or add-on name.

## Rules

- **At least**: how many the customer must choose. 0 means optional; 1 or more makes the group **Required**.
- **At most**: how many they may choose, or **No limit**.
- **Pre-selected**: an add-on chosen for the customer unless they change it (for example "Regular sugar").

## Create an add-on group

1. Press **New add-on group** (or **N**).
2. **Name**, for example "Milk".
3. **At least** and **At most** (or **No limit**).
4. **Add-ons**: a name and a price for each (leave the price empty for free), tick **Pre-selected** where it applies, **Add another** for more. At most 30.
5. Press **Create**. The group's own page opens.
6. Offer it on a menu item: open the item, **Add-ons → Add add-on group**.

## The group's page

Open a group from its card (**Manage**). On a phone, use the tabs to switch between add-ons and settings.

- **Add add-on**, or click an add-on's name to edit its name and default price.
- **Preselected**: tick or untick; saved at once.
- **Archive add-on** from its row's menu: customers stop seeing it; **Show archived** lists archived ones to restore.
- **Reorder**: move add-ons, then **Save order**.
- **Settings**: group name, **Selection** (Minimum and Maximum selections, **No maximum**). Press **Save changes**.
- **Used by**: the menu items that offer this group, each a link to the item.

## Prices and rules per item

The library's prices and rules are defaults. On a menu item you can set a different price for an add-on, or turn on **Own rules for this item**. Those stay on the item when the library changes.

## Archive or restore a group

**Archive group** (in the group's ⋮ menu): items that offer it keep it, but it can't be added to other items, and it's read-only until **Restore group**.

## Common problems

- **"There is already an add-on group named …"** / **"This group already has an add-on named …"**: names must be unique.
- **"This add-on group is archived. Restore it first."**
- **"The add-ons of this group changed. Reload it and try again."**: someone else edited it; press **Reload**.
- **The rule looks wrong on one item**: that item may have its own rules; open the item's Add-ons section.
